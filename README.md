# GraphRAG: Knowledge Graphs & GraphDB with LangChain & Groq

A lightweight, practical implementation demonstrating how to build a **Knowledge Graph** in **Neo4j** and query it using a **Groq LLM** via the **LangChain** framework. This repository showcases how to combine structural graph data with Large Language Models for advanced Retrieval-Augmented Generation (GraphRAG).

---

## 🚀 Overview

Traditional RAG relies on vector semantics, which can lose structural context. This project builds a **GraphRAG pipeline** that extracts entities and relationships from unstructured text, stores them in a Graph Database, and uses an LLM to generate highly contextual answers by traversing the graph.


---

## 🛠️ Tech Stack & Key Concepts

*   **Graph Database:** [Neo4j](https://neo4j.com) — Storing nodes, edges, and complex relationships.
*   **LLM Orchestration:** [LangChain](https://langchain.com) — Connecting the document transformers, graph stores, and LLM chains.
*   **Inference Engine:** [Groq Cloud](https://groq.com) — Fast, low-latency LLM execution (using models like Llama 3).
*   **Query Language:** Cypher — Programmatically generated by the LLM to fetch graph data.

---

## 📈 Key Implementation Steps Demonstrated

1. **Graph Construction:** Transforming raw text paragraphs into structured `(:Node)-[:RELATIONSHIP]->(:Node)` formats.
2. **Schema Mapping:** Helping the LLM understand the strict node labels and relationship types available in the database.
3. **Text-to-Cypher:** Leveraging Groq's high-speed inference to translate natural language user questions into accurate Cypher queries.
4. **Context Synthesis:** Merging structural graph results back into the LLM prompt for final answer generation.
